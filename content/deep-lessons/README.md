# Detailed teaching material

`Dxx.deep` records are authored topic-specific extensions, keyed by stable atlas ID. Each record has five pipe-separated fields:

`ID | mechanism | types and distinctions | worked case | application checklist`

Use `~~` between paragraphs and between case setup, ordered reasoning, result and interpretation. Use `;;` between distinct type entries and checklist steps. A type entry is `name: explanation`.

The case is an additional teaching example, separate from the existing topic assessment. Keep assumptions explicit and preserve assessment answer hiding. Do not turn a broader domain guide into a purported definition of every topic's own types.

Domain study guides support all topics and are labelled as broader context. Coverage distinguishes topic-specific extensions from those shared guides. The source atlas and downloadable master documents retain their stable topology.
